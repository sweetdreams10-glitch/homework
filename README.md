# 🚀 수학 우주 탐험대

초등 3학년 수학 퀴즈 웹앱입니다. 문제를 맞힐 때마다 로켓이 행성을 지나 우주를 탐험해요.

**▶ 바로 실행:** https://sweetdreams10-glitch.github.io/homework/

## 무엇을, 누구를 위해
- **대상:** 초등 3학년 학생과 담임 교사
- **단원:** 세 자리 수 덧셈·뺄셈, 나눗셈, 곱셈, 시간 계산 (2022 개정 교육과정 3학년)
- **수업 장면:** 아침활동 5분 연산 연습, 단원 마무리 형성평가, 수업 끝 복습

## 주요 기능
- 🌍 행성(단원) 5개, 매번 새로 만들어지는 문제, 자주 하는 실수로 만든 오답 보기
- ⚡ 적응형 난이도 (2연속 정답이면 UP, 2연속 오답이면 DOWN)
- ✍️ 보기 선택형과 키패드 직접 입력형
- 🔥 콤보 보너스, 칭호, 배지 도감, 오답 노트 복습
- 🏆 반별 명예의 전당, 개인 최고 기록 비교, 반 협동 별 모으기, 오늘의 미션
- 🧑‍🏫 선생님 화면: 단원별 정답률, 많이 틀린 유형, 학생별 약한 유형

## 기술
- HTML/CSS/JavaScript 파일 하나 (`index.html`)
- Firebase Cloud Firestore에 기록 저장
- 보안: Firestore 보안 규칙(`firestore.rules`), API 키 HTTP 리퍼러 제한
- 배포: GitHub Pages
